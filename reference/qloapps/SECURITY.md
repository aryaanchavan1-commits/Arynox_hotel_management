# Security Policy

Arynox_Hotel_ERP values the contributions of the security research community, and we look forward to working with you to minimize risk to Arynox_Hotel_ERP users.


## Reporting a Security Issue

If you have found a security issue in Arynox_Hotel_ERP, please do not use the issue tracker and don't publish it publicly. Instead, report the security issue to support@arynoxhotelerp.com or contact Arynox_Hotel_ERP Support. So that we can act on it immediately to avoid as much damage as we can.
